<h1 align="center">Alexander Sharp</h1>

I build small tools for radio, signals and recon. Most of them exist because I
wanted one job done without a window full of distractions.

## What I work on

- Internet radio and audio stream control
- SDR, scanners and spectrum listening
- Recon and OSINT workflows
- Windows and Linux automation

## Current project

**[hacker-radio](https://github.com/AlexanderSharp/hacker-radio)** is a single
window radio console for hacker, ambient and scanner streams. VLC runs headless
behind a local browser UI, and search covers the Radio-Browser catalogue.

## Stack

Python, PowerShell, VLC, Linux, SDR.
